# Mixfont font fixture

`mixfont-standard.ttf` is the unmodified **Iridescent Bubbletone** TTF linked in
[Mixfont's official generation guide](https://www.mixfont.com/docs/guides/font-generation)
for the prompt “a cute and bubbly font”. Retrieved on 2026-10-20 from:

https://static.mixfont.com/assets/20260603-215639-font-001-iridescentbubbletone-regular-y1pt732y.ttf

[Mixfont's generated-font license](https://www.mixfont.com/license) permits use,
modification and redistribution. The fixture exercises real generated TrueType
outlines, character coverage, browser loading and byte-identical downloads.
It is test data, not a live response from our configured API account or a public
product example. Tests use this local copy and make no paid API requests.
