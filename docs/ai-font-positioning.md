# AI Font 定位与首版差异化（2026-10-06）

## 核实的竞品信息

来源为当日公开页面，不代表对实际生成质量的实测。

- [YoFont Plans](https://yofont.com/plans)：Starter $9/月，1,000 字形；Pro 正常价 $19/月，10,000 字形，页面显示首月 $9.50 限时优惠。Pro 包含商用和私有字体；支持字形编辑、补充语言/字重以及多格式下载。不同模型消耗和输出质量不能按字形数直接换算成等价的完整字体。
- [YoFont 首页](https://yofont.com/zh/)：宣传多文字系统及多语言字体生成。首页与价格页对免费下载的表述不一致，因此不在本站放“对方免费版不能下载”的营销比较。
- [Mixfont Pricing](https://www.mixfont.com/pricing)：Free 含 50 网站积分和生成结果下载；Pro $20/月含 1,000 网站积分。网站积分不能当作 API 单价。
- [Mixfont Generation API](https://www.mixfont.com/font-generation-api)：支持文字/参考图片生成 TTF，standard 72 字形、extended 319 字形。本站当前只接入文字、standard，不能宣传中文或完整字体家族。

## 选择的路线

面向偶尔做标题、邀请函、社交图片的用户：一次购买，从字体到可用图片。
$4.99 三次生成的付款门槛低于对方月费，但不能宣称单位产出更便宜。
私有字体库、无需订阅、额度没有每月重置，配合可直接导出 PNG 的编辑器，
构成小项目的方便入口。这是待验证的定位，不是已证明的质量或转化优势。

本轮交付：参考字体免费排版、真实生成字体接入同一编辑器、文字/颜色/
字号/对齐编辑、三种画布、无水印 PNG、透明背景。排版和导出在浏览器
完成，不新增生成 API 调用。价格和额度保持不变，原有免费工具不改动。

## 上线前仍需验证

1. 配置生成服务后，用实际样本检查完整字符、间距、描述符合度、耗时和失败率；取得可展示的真实结果。现有参考字体不能包装成 AI 案例。
2. 确認 API 实际账单、Waffo 支付费用及退款成本后再决定是否增加次数。每包贡献 = 实收 - 支付费用 - 三次生成的预期成本 - 存储/流量及支持成本。需要同时考虑失败是否被上游收费。
3. 接入 Waffo 并验证支付、重复回调、退款及额度结算；本轮未替换 PayPal。
4. 先观察免费编辑器使用、购买转化、生成完成和实际导出，再决定图片生成字体、字形编辑等重功能的优先级。PNG 排版不等于修改字体字形。
