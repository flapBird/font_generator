# AI Font 定位与首版差异化（2026-10-06）

## 核实的竞品信息

来源为当日公开页面，不代表对实际生成质量的实测。

- [YoFont Plans](https://yofont.com/plans)：Starter $9/月，1,000 字形；Pro 正常价 $19/月，10,000 字形，页面显示首月 $9.50 限时优惠。Pro 包含商用和私有字体；支持字形编辑、补充语言/字重以及多格式下载。不同模型消耗和输出质量不能按字形数直接换算成等价的完整字体。
- [YoFont 首页](https://yofont.com/zh/)：宣传多文字系统及多语言字体生成。首页与价格页对免费下载的表述不一致，因此不在本站放“对方免费版不能下载”的营销比较。
- [Mixfont Pricing](https://www.mixfont.com/pricing)：Free 含 50 网站积分和生成结果下载；Pro $20/月含 1,000 网站积分。网站积分不能当作 API 单价。
- [Mixfont Generation API](https://www.mixfont.com/font-generation-api)：支持文字/参考图片生成 TTF，standard 72 字形、extended 319 字形。本站当前只接入文字、standard，不能宣传中文或完整字体家族。

## 上线前仍需验证

1. 配置生成服务后，用实际样本检查完整字符、间距、描述符合度、耗时和失败率；取得可展示的真实结果。现有参考字体不能包装成 AI 案例。
2. 确認 API 实际账单、Waffo 支付费用及退款成本后再决定是否增加次数。每包贡献 = 实收 - 支付费用 - 三次生成的预期成本 - 存储/流量及支持成本。需要同时考虑失败是否被上游收费。
3. 接入 Waffo 并验证支付、重复回调、退款及额度结算；本轮未替换 PayPal。
4. 先观察免费编辑器使用、购买转化、生成完成和实际导出，再决定图片生成字体、字形编辑等重功能的优先级。PNG 排版不等于修改字体字形。

## API 成本复核（2026-10-20）

- [Mixfont API Pricing](https://www.mixfont.com/docs/pricing)：1 API credit = $0.01；standard 为 20 credits，即 $0.20/次；extended 为 $0.50/次。按控制台显示的 $10 起充计算，可提交 50 次 standard 请求。公开文档未列出最低充值金额，因此 $10 门槛以账户实际结账为准；不把网站免费积分、网站订阅额度当作 API 额度。
- [YoFont Plans](https://yofont.com/plans) 与 [API/MCP](https://yofont.com/api-mcp)：当前 Pro 为 $19/月、5,000 字形，包含 API 和商用；更强模型按 ×3/×5 消耗。按 standard 模型每次 100 字形且完全用完月额度估算，约 50 次、$0.38/次；实际覆盖量及质量不等同于 Mixfont。少量使用仍需承担整月费用，不能据更低的网站套餐价认定 API 更便宜。
- [MakeAFont API](https://makeafont.com/api/)：good 为 400 tokens/次，网站与 API 共用额度；[首页](https://makeafont.com/)展示 €1.99/4 次，付费门槛更低，但产物主要是彩色字体，[文件再分发需 Seller 权限](https://makeafont.com/license/)，不能按该入门价格直接替代本站的可下载字体交付服务。
- [Lipi API](https://www.lipi.ai/docs/font-generate-api)：文字生成每次 10 credits，申请 API 赠送 10 credits，可作为一次评估机会；本次未查到可靠的公开美元充值换算及与本站相符的文件转售授权，不把它算成已确认更便宜的生产替代。

结论：在本项目目前少量、按需、自动生成并交付英文 TTF 的场景中，继续使用 Mixfont 可避免新增订阅和迁移成本；不能宣称其为全市场绝对最低价。用户仅需排版时，现有参考字体预览和 PNG 导出无需付费 API。自行维护“图片生成字形 → 分割/描摹 → TTF 编译”还需计算重试、字符识别、间距和维护成本，不只比较图片生成报价。

当前交付增加了文件表结构、校验和、字形解码以及核心英文字符检查；无效文件按失败流程恢复用户本次预扣积分。预览从实际下载文件读取字符覆盖，缺字显示提示。离线测试使用官方公开 TTF 样本和模拟 HTTP，不代表已完成本账户真实付费生成、上游退款或桌面设计软件安装验收。
