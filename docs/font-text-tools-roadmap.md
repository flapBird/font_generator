# Font & Text Tools 扩展计划

记录日期：2026-10-29。用户已同意按本计划顺序执行，并明确要求不得影响现有生成器。

## 判断与实施边界

优先验证 Symbols / Kaomoji / Emoji Combos 的自然搜索与重复使用需求，再补 Unicode 实用工具、签名。字体文件工具主要验证 AI 字体生成后的实际使用需求，不假设符号用户会购买 AI 字体。

用户报告引用 Semrush 2026 年 9 月估算：EmojiCombos 1553 万访问，Fsymbols 275 万访问。历史月份数字仍需对应导出记录复核；这是全站访问估算，不是单工具流量或本站增长预测，不作为承诺收益的依据。参考：https://www.semrush.com/website/emojicombos.com/overview/ 和 https://www.semrush.com/website/fsymbols.com/overview/ 。

基线核对：本地注册表有 57 个 Unicode 工具、27 个视觉工具及 1 个目录；本次读取的线上目录显示 50 / 24，需在下一次发布时核对部署版本与抓取缓存。没有读取 Search Console 或 GA4 私有报表，不编造流量、转化或收入基线。

已有 Emoji 字母转换、真实手写字体 PNG/SVG 导出、文字转 ASCII 横幅。新增组合内容库、签名和图片转 ASCII 必须保持用途独立，不替换旧页面。

## 第一批页面与功能

| URL | 内容与用途 |
| --- | --- |
| `/symbols` | 符号浏览总入口，分类、名称/码点搜索，专题链接 |
| `/symbols/heart-symbols` | 文字心形、Emoji 心形、装饰的区别与复制 |
| `/symbols/star-symbols` | 实心、空心、闪光与星形装饰 |
| `/symbols/arrow-symbols` | 方向、线条形态与排版箭头 |
| `/kaomoji` | 开心、伤心、爱意、动作等颜文字 |
| `/emoji-combos` | 人工整理的主题组合，添加与编辑 |
| `/unicode-tools` | 已实现 Unicode 工具目录和用途说明 |
| `/invisible-character` | 空白类型选择、1–100 次重复、准确复制、粘贴检测 |

内容预算：约 200–300 个去重符号、100 个颜文字、100 个 Emoji 组合。数量是编辑预算，不是 SEO 门槛。基础名称来自 Unicode 字符数据，组合与说明自行整理，不抓取竞品内容。保留数据来源说明。cute/aesthetic 先作为分类，不创建同义重复页；不提供用户投稿。

符号工作区独立实现：服务端初始输出真实可复制条目；浏览、搜索、筛选、整卡复制、键盘操作；复制失败提供手动复制；组合区添加、排序、移除与编辑；最近使用及收藏保存在本机，无需账户。用户输入与组合不发送到分析服务。

Invisible Character 区分普通空格、不换行空格、零宽空格等不同语义，并提供字符检查；不保证任何平台接受空白昵称。采用独立实用工具工作区与 Unicode 页内导航，直接展示字符选择、准确复制和粘贴检测，不加载字体工作区的侧栏与艺术字预览。不得使用 trim() 判断这些输出是否可复制。

## 后续批次验收边界

- Unicode Inspector 显示码点和字素；Remover 先检测再选择移除类型，预览前后差异，默认不破坏 ZWJ Emoji 和文字连接符。
- Fancy Text to Normal Text 仅承诺已支持映射，说明信息丢失与 NFKC 的限制，不宣称万能恢复。
- 签名独立工作区，先选 6–8 款有明确许可的字体，鼠标/触控手绘、颜色、大小、撤销、清空、自动裁切、透明 PNG。SVG 后续验证路径与字体依赖后再增加；不承诺文件签署服务。
- Image to ASCII 保留旧 Big Font 行为，按亮度与字符密度生成，验证长宽比与 TXT/PNG 输出。
- 字体文件先做本地预览、元数据、覆盖信息，再验证静态 TTF/OTF → WOFF2 与 CSS/示例打包。比对 cmap、字形、布局表、浏览器渲染；明确拒绝未支持可变/彩色字体和字体集合。OTF → TTF 单独评估，不改扩展名伪装转换。

## 旧生成器影响范围与隔离策略

- 不修改 `lib/generator.ts`、`lib/fonts.ts`、旧页面数据、旧注册表分类、公共工作区默认行为、旧默认值和输入限制。
- 新工具使用独立目录，避免现有注册表将所有非 Unicode 工具自动归入 Visual & Art。
- 只增量接入目录链接、sitemap、内容更新时间及 llms.txt。顶部/页脚新增目录入口，保留原入口顺序；旧侧栏、手机快捷栏及“查看更多”位置不动。
- 页面专属组件和数据仅由新路由引用；不新增全站字体、CSS、外部服务或依赖。
- 分析事件只扩展新页面专用调用，遵守现有开关，不改变现有购买与登录事件。只记页面/操作/条目 ID，不记用户输入、组合原文或上传内容。
- 实际共享改动影响：首页和所有页面的目录可达性、sitemap、llms.txt。对此做桌面/手机导航与旧页面回归，不据新页通过就宣称全站无影响。

## 使用指标与上线后复盘

已接入 `tool_copy_success`、`tool_copy_failure`、`tool_combine`、`tool_favorite`、`tool_filter`、`tool_directory_click` 和签名的 `tool_export_success`。事件只含固定 `tool_id`、可选 `item_id` 和经过清理的页面位置，不包含用户内容。复制成功以 Clipboard API 完成计；手动复制回退不冒充成功。导出事件表示浏览器已发起下载，不证明用户保存成功。首版不上报任意搜索词，也不区分每一次组合重排或删除；分类使用事件目前仅标识工具，不携带分类值。复用原生产域名限制和分析停用开关，未修改 AI 字体购买事件或 GA 后台配置。

上线后第 2/4/8 周：查看收录/canonical、查询展示与点击、成功复制的访问占比、失败率和分类使用。未收录先排查抓取/内容，有展示少点击检查意图，有访问少复制检查体验；数据不足延长观察。复制后离开可以是任务成功，不仅按跳出率判断。复盘依赖部署与真实报表，本轮不创建定时任务或编造数据。
