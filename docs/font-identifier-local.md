# 本地字体识别首版

2026-11-01。用户选择浏览器本地方案，不接入付费识别 API。

## 已实现边界

- `/font-identifier`：PNG/JPEG/WebP 文件或工作区粘贴截图，最多 10 MB / 20 MP；浏览器缩放到最长边 1600px。指针拖动或数字坐标裁切，独立 Worker 识别，取消及 60 秒超时，最多十个字体候选。
- `/font-tools`：有 What / How to / FAQ 的独立分类目录。只增量加入 `/tools`，不增加顶栏/页脚精选分类，不改变旧生成器常驻导航或转换逻辑。
- 固定 `gpu-font@0.4.2`，仅打包 Google Fonts 索引。网页缓存曾显示 0.4.3，但实际 npm 尚无该版本，因此以实际安装包为准。保留 MIT LICENSE，未复制其它来源目录、未分发字体文件。
- `scripts/prepare-font-identifier.mjs` 从锁定依赖生成忽略跟踪的静态资产；`prebuild` 和 `predev` 自动执行。保持源目录关系，模型与索引的哈希由上游引擎校验。没有额外服务端识别接口、API Key 或按次费用。
- Worker 只在用户点击 Identify 时启动；支持 WebGPU / CPU 回退，终止 Worker 可取消 CPU 运算；更换图片或裁切会取消旧请求并清除过期候选。旧页面不加载识别代码或模型。
- 图片、裁切像素和比较文本不上传、不持久化。可选字体预览按用户点击请求 Google Fonts CSS 和字体，可加载单个候选或当前可见候选；URL 仅含字体名称、样式、字重，不包含图片或比较文本。加载失败明确提示，不把回退字体冒充真实预览。
- 结果是候选，不显示伪造准确率，不保证识别库外字体。不自动下载字体文件，不涉及账号积分与 AI Font 生成。

模型 JSON 511,939 字节，Google Fonts 索引 4,050,051 字节；本机 gzip 合计 1,431,402 字节。实际传输大小取决于部署压缩和缓存配置，不把 gzip 数值当成所有环境的必然值。npm 整包较大，但其它目录不会被复制到公开资源。

## 验证与限制

首轮本地 Chromium 实际识别：Anton、EB Garamond、Luckiest Guy、Oswald 各一张清晰 PNG 和 JPEG quality 0.4，共八张。正确家族全部排第一，单次 3.8–11.6 秒（含加载与执行）。这是已知开源字体、可控渲染样本，不能推导真实截图或照片的识别率；不是独立于模型训练集的评测。测试保留真实引擎执行，并另验证 CPU 回退。

尚未完成：真实用户照片/商标、库外字体的系统评测，实体手机性能和 Safari 验证。无字体拒识保证，CPU 慢设备可能触发超时；因此对外明确标为 experimental。未部署或调用付费 API。

验证结果：

- `npm run lint`、`npm run build`、`npm run test:generators` 均通过；原 59 个转换和 65 个页面定义快照保持兼容。
- `node --import tsx --test tests/text-library/*.test.ts`：13 项通过。
- Playwright 生成器全量回归 77 项通过；随后新增的粘贴、指针/键盘裁切、预览加载失败与重试、裁切清理旧候选专项 1 项通过，共 78 项不同用例。预览 UI 专项使用受控候选和本地字体响应，不作为外部 Google Fonts 可用性保证。
- 强制 CPU 回退的八张真实引擎测试均将正确家族排第一，本机单次 3.3–3.9 秒；该结果仍仅适用于上述可控样本。
- 检查 320/390/1440px 页面无横向溢出，查看手机与桌面候选截图；验证实际 `/llms.txt`、sitemap、canonical、SSR 内容与目录搜索。原首页、Small Text、Cute 等不请求新模型；旧文本/图片工具的复制、导出、导航及输入隔离回归通过。
- 已核对 `llms.txt` 与当前功能、模型按需加载、免费范围及数据处理方式一致。未更改旧生成器转换、默认值、规范 URL 或常驻入口。

## 识别与比较界面改版

- 按已确认的 Claude Design 方案实现 `/font-identifier` 分步选图、裁切、识别、结果界面；保持现有 URL、canonical、Worker、模型及限制。没有修改 `/font-tools`、首页、共享导航、全局样式或生成器转换函数。
- 选图页支持原有文件选择和粘贴，并新增真实样例图片入口。样例会经过同一模型，不使用画布中的演示候选。样例 PNG 是本地 Georgia 排字的栅格图，不分发字体文件。
- 裁切画布保留鼠标／触摸指针操作，数字裁切收进可展开的 Adjust crop coordinates。修改裁切、换图或返回裁切均清除过期候选和字体预览。
- 识别状态展示真实加载／匹配阶段，不显示虚构百分比；保留取消、60 秒超时和重试。阶段切换将键盘焦点移至标题。
- 结果区就近展示裁切原图、选中字体、比较文字和 20–76px 字号。初始三个候选，可展开最多十个；手机采用紧凑选项卡，选中时回到比较区域。字体加载成功才显示真实字样；可单独加载候选或批量加载当前可见候选。
- 保留并同步服务端 What / How to / FAQ 和 FAQ 结构化数据；`llms.txt` 同步新流程和按用户操作加载字体的边界。
- 改版验证：生产构建、类型检查、lint、生成器基线检查通过；共八项不同 Playwright 用例通过，包括识别及旧页面输入隔离六项、旧工具 Unicode／Emoji 复制及桌面／手机导航两项。识别覆盖八张真实 CPU 回退样本、预览失败／重试、十候选展开、网络请求隐私、指针／数字裁切、取消和超时恢复；最终构建上重复通过三个界面用例。已检查 320/390/1440px 布局及桌面、手机、深色模式截图。外部 Google Fonts 预览测试使用受控字体响应，不代表外网可用性测试；未验证实体手机或 Safari。

## 流量下降的初步检查

用户反馈 GSC 自然搜索点击和 GA 总访问均下降，待提供 GSC 数据。当前不能确认下降日期、幅度、受影响页面或上线版本。

本地代码：robots 允许抓取；公开 sitemap 使用独立 canonical URL；旧 `/style/:slug`、`/styles/:slug`、`/fandom/:slug` 重定向到根路径规范页。生成构建的四百余路由包含旧路径重定向，并不等于四百个独立索引内容页。最近历史含导航/页脚重组、首页文字与标题调整；`c25ab0c` 的“重设计主要页面”只改设计画布文件，不能把该 commit 当成生产页面改版证据。

需以部署时间与 GSC 对比检查：

1. 同长度、同星期构成的前后周期，排除未完整统计的最新日期；看总点击/展示/CTR/排名。
2. 按页面×查询定位下降源：原高流量页下滑，还是新增低排名页改变了全站平均值；同一查询是否在多个本站 URL 间切换。
3. 对受影响旧页核对生产状态、canonical、索引原因、内部链接层级与标题变化；GSC 抓取/索引错误是否同期增加。
4. 展示/排名稳定而点击减少偏向 CTR；展示减少而排名稳定需看搜索需求；GSC 稳定而 GA 下降才优先排查统计采集。本次两者都下降，不能只归因于 GA。

没有证据支持“页面数量一增加就稀释权重”，也没有证据支持现在删页、批量 noindex 或改 URL。Google 官方建议依页面/查询/日期分析流量下降，而不是单看页面数量：
